# Sanjay Shaw — GitHub Profile README

1. Create a **public** GitHub repository named exactly your GitHub username.
2. Upload the files from this package to the repository root.
3. Open **Actions → Update GitHub Profile → Run workflow** once.
4. GitHub Actions will regenerate the contribution SVG daily.
5. Replace the placeholder LinkedIn link in `README.md` with your real profile.

The profile intentionally avoids third-party GitHub stats services. The activity graphic is generated from GitHub's GraphQL API by your own GitHub Action.
